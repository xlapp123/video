# VisionPro Studio 4K 视频画质增强工作站 (PWA 版)

## 一、快速部署到 GitHub Pages
1. 在 GitHub 上创建一个新的公开仓库（例如 `visionpro-4k-player`）。
2. 将本压缩包解压后的所有文件（`index.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`）上传到该仓库的根目录。
3. 打开仓库的 **Settings（设置） -> Pages**。
4. 在 **Build and deployment -> Source** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。
5. 等待约 1 分钟，GitHub 会生成 HTTPS 访问网址（例如 `https://你的用户名.github.io/visionpro-4k-player/`）。

## 二、安装到手机桌面（作为独立 App 使用）
- **iPhone / iPad (Safari 浏览器)**：
  1. 用 Safari 打开上述 GitHub Pages 网址。
  2. 点击底部工具栏的 **「分享」按钮**。
  3. 向下滑动并点击 **「添加到主屏幕」**，即可在桌面生成独立全屏应用图标。
- **Android 手机 (Chrome / Edge 浏览器)**：
  1. 用 Chrome 打开上述网址。
  2. 点击右上角菜单 **「⋮」 -> 「安装应用」或「添加到主屏幕」**（或直接点击页面顶部的「安装桌面App」按钮）。
